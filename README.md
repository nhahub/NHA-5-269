# HR Analytics & Employee Attrition Prediction

## Project Overview
This project focuses on analyzing the historical IBM HR dataset to uncover key factors influencing voluntary employee turnover. Using data science techniques and predictive machine learning models, the system enables HR management to proactively identify attrition risks and optimize workforce retention strategies.

## Key Objectives
- Identify key attrition drivers (OverTime, Compensation, Career Growth, Job Satisfaction).
- Build a predictive ML model to estimate employee flight-risk scores.
- Create an interactive Power BI dashboard for executive HR decision-making.

## Tech Stack
- **Languages:** Python 3.x
- **Libraries:** Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib
- **BI & Visualization:** Power BI Desktop
- **Version Control:** Git & GitHub
