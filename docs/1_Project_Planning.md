# 1. Project Planning & Management

## Project Proposal Overview
* **Title:** HR Analytics & Employee Attrition Prediction
* **Domain:** Human Resource Management & Business Intelligence
* **Scope:** Analyzing 1,470 IBM employee records across 35 attributes to identify key turnover drivers, predict resignations using Machine Learning, and deliver actionable HR data insights via Power BI dashboard.

## Task Assignment & Roles
* **Amin Mahmoud:** Data Analyst & HR Specialist (Data Cleaning, HR Metric Mapping, EDA, SOP Alignment).
* **Team Member 2:** Machine Learning Engineer (Preprocessing, Model Training & Evaluation).
* **Team Member 3:** BI Developer (Power BI Dashboard Architecture & Visualization).
* **Team Member 4:** Documentation & QA Lead (Requirements Gathering, GitHub Management, Testing).

## Risk Assessment & Mitigation Plan
1. **Risk:** Class Imbalance in Attrition Data (~16% Yes vs 84% No). 
   * *Mitigation:* Apply SMOTE or class weighting algorithms in Python.
2. **Risk:** Data Quality & Missing Values. 
   * *Mitigation:* Build automated Python cleaning script using Pandas.
3. **Risk:** Time Constraint & Deadline Pressure. 
   * *Mitigation:* Divide tasks into clear weekly deliverables and use Git version control.

## Key Performance Indicators (KPIs)
* Model Precision & Recall > 80% for predicting attrition.
* Dashboard interactive responsiveness < 2 seconds.
* 100% adherence to DEPI project documentation guidelines.
